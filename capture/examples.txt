──────────────────────────────────────────────────────────────────────────────
ARGUMENTS
──────────────────────────────────────────────────────────────────────────────

  --board           Short label for the board (required). Used in dir name and meta.json.
  --port            Serial port (required). e.g. /dev/tty.usbmodem101
  --num-traces      Number of traces to capture. Default: 2000
  --out-dir         Output directory. Auto-generated as data/set_NNN_<board> if omitted.
  --baud            UART baud rate. Default: 115200
  --serial-delay    Seconds to wait after opening serial (use 2.0 for UNO R4). Default: 0.5
  --scope-address   PyVISA resource string (USB). Default: USB0::0x2A8D::0x17B6::MY65060127::INSTR
  --scope-ip        Scope IP for Ethernet. Builds TCPIP VISA address. Overrides --scope-address.
  --scope-protocol  Ethernet protocol: hislip (default), vxi11, socket.
  --scope-channel   Oscilloscope channel for power trace. Default: CHANnel1
  --scope-points    Waveform points downloaded per trace. Default: 5000
  --notes           Free-text capture notes written into meta.json.
  --precompute-images  Run GASF/GADF/RP/MTF image encoding after saving (creates images_S64.h5).
  --no-plot         Skip overview plot generation after capture.
